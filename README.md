## Overview

ADVANTE is an AI-powered Web GIS platform for government land administration, GIS surveyors, and land record officers. It integrates and harmonizes multi-source land claim data — starting with Individual Forest Rights (FRA-style) claim records for Ozar village — into unified, verified Golden Land Records per cadastral survey number.
